# Katalog guruhlari — muqova rasmlari

"Umumiy katalog" sahifasidagi 10 ta katta kartochka va guruh ichidagi yuqori rasm shu papkadan olinadi.
**Fayl shu papkaga tushishi bilan o'zi ulanadi — kodni o'zgartirish shart emas.** Rasm bo'lmasa kartochka
gradient va emoji bilan ko'rinadi.

## Fayl nomlari (aynan shunday, kichik harflarda)

| Fayl | Guruh | Ichida |
|---|---|---|
| `gosht.webp` | Go'sht mahsulotlari | mol, qo'y, parranda, kolbasa, baliq |
| `sut.webp` | Sut mahsulotlari | sut, pishloq, sariyog', tuxum, muzqaymoq |
| `sabzavot.webp` | Sabzavotlar | yangi sabzavot, ko'katlar, tuzlama, tomat |
| `meva.webp` | Mevalar | yangi va quruq meva, yong'oq, murabbo, asal |
| `don.webp` | Yormalar va donlar | guruch, un, makaron, dukkakli |
| `ichimlik.webp` | Ichimliklar | suv, sharbat, gazli, choy, qahva |
| `non.webp` | Non va qandolat | non, pishiriq, pechenye, shokolad, konfet |
| `ziravor.webp` | Ziravorlar va souslar | ziravor, tuz, sous, yog', sirka |
| `tayyor.webp` | Tayyor va muzlatilgan | yarim tayyor, konserva, fast-food, milliy |
| `uyrozgor.webp` | Uy-ro'zg'or | kimyo, gigiyena, idish, qadoq |
| `boshqa.webp` | Boshqa | guruhga kirmagan mahsulotlar |

`.webp`, `.jpg`, `.jpeg`, `.png`, `.avif` qabul qilinadi.

## Tavsiya

- O'lcham **1200×900** (4:3), gorizontal; asosiy narsa o'rtada (tepa va pastdan biroz kesilishi mumkin).
- Hajm **150 KB** dan kam (WebP, sifat ~80) — sahifa tez ochiladi.
- Pastki qismi kartochkada qoraytiriladi (matn o'qilishi uchun), shuning uchun rasmning pastida muhim narsa bo'lmasin.

## Mahsulot rasmlari

Alohida mahsulot rasmlari bu yerda emas: ular bazada saqlanadi. Qo'shish yo'llari: «ZIP orqali» (data.json + images/),
yoki mahsulot kartochkasidagi «Rasm qo'shish». Guruh ichida filtr → «Rasmsiz» rasmi yo'q mahsulotlarni ko'rsatadi.
